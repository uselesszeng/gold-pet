# 黄金桌宠 PRD（产品需求文档）v0.1

> 一句话定义：**一只住在桌面右下角的"金娘"，实时盯着金价，涨了开心、跌了难过，点一下就能看到最新价格。**

## 1. 项目目标

| 项目 | 内容 |
|---|---|
| 产品名 | 黄金桌宠（Gold Pet / 金娘） |
| 定位 | 轻量桌面挂件，把"查金价"从打开网页/APP 变成"看一眼桌面" |
| 目标用户 | 关注金价的中国用户：买金饰/金条的人、做黄金 T+D / 积存金的人、纯好奇的围观群众 |
| 一期平台 | **Windows**（后续 Android、鸿蒙 HAP） |
| 核心价值 | 零操作步骤的实时金价感知 + 一点点陪伴感 |

### 非目标（一期明确不做）
- 不做交易、不接券商/银行账号、不提供投资建议
- 不做复杂图表（K 线/技术指标），气泡里只有迷你走势
- 不做账号体系、不做云同步

## 2. 使用场景

1. **路过看一眼**：写文档/摸鱼时余光扫到右下角，知道今天金价大概什么水平
2. **到价提醒**：设定"跌破 880 元/克叫我"，触发后气泡高亮 + 托盘通知
3. **盘中关注**：开会/午休时不用解锁手机，气泡手动刷新即可
4. **桌面陪伴**：点一下金娘它会反应（眨眼/转圈/说话）

## 3. 功能需求

### P0（一期 MVP，本次实现）
| 编号 | 功能 | 说明 |
|---|---|---|
| F1 | 桌宠窗口 | 无边框、透明背景、置顶、可拖动、位置记忆、开机自启可选 |
| F2 | 帧动画 | 待机（呼吸+眨眼）、涨（笑）、跌（哭）、加载中、断网 5 种状态 |
| F3 | 价格气泡 | 显示「国内金价 897.15 元/克 ▲ +3.2 (+0.36%)」+ 更新时间，点击切换 国内/国际 |
| F4 | 定时刷新 | 默认 60s，可选 15/30/60/300s；手动刷新；失败自动退避重试 |
| F5 | 托盘图标 | 右键菜单：显示/隐藏、立即刷新、切换单位、设置、开机自启、退出 |
| F6 | 设置面板 | 刷新间隔、默认单位、涨跌提醒阈值、不透明度、是否置顶、开机自启 |
| F7 | 到价提醒 | 涨跌幅超过阈值 → 气泡高亮 + 系统通知（去重、不刷屏） |
| F8 | 离线兜底 | 断网/接口异常 → 显示"离线"状态 + 上次价格和时间，不崩溃 |
| F9 | 单位换算 | 国内 元/克（Au T+D）、国际 美元/盎司（伦敦金），汇率换算 |

## 4. 数据来源与计算

| 数据 | 来源 | 说明 |
|---|---|---|
| 国内金价（元/克） | 新浪财经 `gds_AUTD`（上海黄金交易所 Au T+D） | 免密钥、含昨收/最高/最低 |
| 国际金价（美元/盎司） | 新浪财经 `hf_XAU`（伦敦金现货） | 免密钥 |
| 汇率 USD/CNY | 新浪财经 `fx_susdcny` | 用于换算校验 |

- 换算：`元/克 = 美元/盎司 ÷ 31.1034768 × 汇率`
- 涨跌：`涨跌 = 现价 - 昨收`；`涨跌幅 = 涨跌 / 昨收`
- 颜色：**涨红跌绿**（符合国内习惯）
- 更新频率：接口为实时行情，本地按刷新间隔拉取即可
- 免责：行情数据仅供参考，来源为第三方公开接口，可能存在延迟，不构成投资建议

## 5. 交互设计

- **桌宠本体**：160×160 透明窗口，默认停在右下角（距边 24px）
- **拖动**：左键按住拖动；短按（<200ms 且移动 <4px）视为点击
- **点击**：切换气泡显示 国内/国际 价格
- **双击**：立即刷新
- **右键**：菜单（刷新 / 切换单位 / 置顶 / 设置 / 隐藏 / 退出）
- **气泡**：始终显示在金娘头顶，宽度自适应，超时无变化则保持不变
- **托盘**：常驻系统托盘，关闭窗口=隐藏到托盘，退出需从菜单选择

## 6. 技术方案（Windows 一期）

| 项 | 选择 | 理由 |
|---|---|---|
| 语言 | Python 3.11+ | 小白友好、改一行就能看到效果 |
| GUI | PySide6（Qt6） | 透明窗口/托盘/打包成熟，LGPL 可商用 |
| 网络 | urllib（标准库） | 零依赖，避免 requests 打包问题 |
| 配置 | JSON（%APPDATA%\GoldPet） | 无数据库，简单可手改 |
| 素材 | Pillow 脚本生成 PNG 帧 | 可自行改参数重画，不依赖美术 |
| 打包 | PyInstaller --onefile --noconsole | 产出单个 exe |
| 自启 | 注册表 HKCU\...\Run | 无需管理员权限 |

## 8. 里程碑与验收

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| M1 | 素材生成 + 行情模块 | 命令行能打印出 897.15 元/克 |
| M2 | 桌宠窗口 + 气泡 + 拖动 | 窗口透明置顶、可拖、价格正确显示 |
| M3 | 托盘 + 设置 + 提醒 + 自启 | 设置可持久化、到价有通知 |
| M4 | 打包 exe | 双击 exe 能跑、可被杀软认可 |

## 9. 风险与开放问题

1. 第三方行情接口可能变更/限流 → 多源兜底 + 缓存 + 明确"离线"状态
2. 打包体积大（PyInstaller + Qt 约 60-80MB）→ 二期可换 Tauri/Electron 对比
3. 杀软误报 → 用 --onefile 并签名（可选）
4. **待用户确认**：默认单位（元/克 or 美元/盎司）、刷新间隔、提醒阈值、金娘形象风格
