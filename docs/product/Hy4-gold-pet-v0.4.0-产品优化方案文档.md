## 一、产品定位（一句话）

给关注金价但不想打开 App 的人，一个零操作、低打扰、会说话的桌面价格感知入口。

- 不是交易工具，不做下单
- 不是行情终端，不做 K 线与指标
- 是「看一眼就知道」的陪伴式挂件

---

## 二、用户与场景

| 用户 | 场景（JTBD） | 当前满足度 |

## 四、体验地图与痛点

启动 → 日常看价 → 提醒 → 设置 → 异常场景

- 启动：首次使用不知道能干什么
- 看价：数字够大，但缺少走势与高低点参照（高低已补，走势时间范围缺）
- 提醒：只有涨跌幅阈值，缺“跌到 880 叫我”
- 设置：项较多，缺少默认值引导与说明
- 异常：断网/休市时用户不知道“为什么不动”

## 五、优化项（RICE 排序）

| 优先级 | 优化项 | 价值 | 成本 | 说明 |
|---|---|---|---|---|
| P0 | 到价提醒（具体价位） | 高 | 低 | 真正刚需，本版已落地 |
| P0 | 休市 / 离线状态标识 | 高 | 低 | 解释“数字为什么不动”，本版已落地 |
| P0 | 首次运行引导 | 高 | 低 | 新用户不知可交互，本版已落地 |
| P1 | 提醒中心（涨跌幅/价位/创新高统一管理与历史） | 高 | 中 | 多规则并列配置，用户难理解 |
| P1 | 托盘图标显示价格数字 | 中高 | 中 | Windows 托盘需动态图标渲染 |
| P1 | 走势时间范围（1 小时 / 今日 / 本周） | 中 | 中 | 现在只有最近 N 点 |
| P2 | 勿扰模式 / 静音时段 | 中 | 低 | 夜间与会议场景 |
| P2 | 多显示器与边缘吸附 | 中 | 中 | 副屏用户 |
| P2 | 气泡主题（深色/浅色/透明） | 中 | 低 | 个性化 |
| P2 | 自动更新检查 | 中 | 中 | 发布后用户不会主动升级 |
| P3 | 音效、节日彩蛋、更多皮肤 | 低 | 中 | 锦上添花 |

## 六、v0.4.0 本次已落地

1. 到价提醒：设置里填「≥ 目标价」「≤ 目标价」（元/克），触发时气泡说话 + 系统通知，带冷却去重
2. 休市标识：非交易时段（含夜盘跨零点、周末）气泡显示「休市」
3. 首次运行引导：第一次启动金娘自我介绍 + 托盘气泡说明交互方式
4. 关于窗口：版本号、数据来源、免责声明、许可
5. 菜单统一：右键与托盘共用一套构建逻辑
6. 历史写入节流：只在联网刷新成功时落盘

## 七、关键指标（建议口径）

| 指标 | 口径 | 目标 |
|---|---|---|
| 日活 | 每日启动次数 ≥ 1 | 观察趋势 |
| 次日留存 | 首次启动后次日仍启动 | 大于 40% |
| 提醒准确率 | 触发提醒中未被关闭的比例 | 大于 80% |
| 崩溃率 | 未捕获异常次数 / 启动次数 | 小于 0.5% |
| 启动耗时 | 进程启动到窗口显示 | 小于 1.5s |
| 安装包体积 | exe 大小 | 小于 60MB（当前 68MB） |

单机软件无账号体系，指标以本地日志为主；若做云统计需明确告知并默认关闭。

## 九、风险与合规

1. 行情来自第三方公开接口，存在延迟与中断：界面明确「离线 / 休市」，并声明不构成投资建议（关于窗口与 README 均已声明）

3. 桌面宠物类软件易被杀软误报：后续建议代码签名
