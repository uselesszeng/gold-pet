# 从源码运行（macOS / Linux）

> Windows 用户请直接下载 [Releases](https://cnb.cool/TJ-coding/gold-pet/-/releases) 里的
> `.exe`，双击即用，不需要看这份文档。

黄金桌宠是 Python + PySide6(Qt6) 写的桌面程序。官方只为 Windows 提供打包好的 exe，
macOS 与 Linux 需要从源码运行。按下面的步骤做，全程约 5 分钟。

---

## 一、先确认 Python 版本

需要 **Python 3.11 或更高**。

```bash
python3 --version
```

- 显示 `3.11.x` / `3.12.x` / `3.13.x` → 继续下一步
- 显示 `3.10` 或更低、或提示命令不存在 → 先装 Python

<details>
<summary>怎么装 Python（点开）</summary>

**macOS**
```bash
# 装了 Homebrew 的话
brew install python@3.12

# 没装 Homebrew，去官网下载安装包
# https://www.python.org/downloads/
```

**Ubuntu / Debian**
```bash
sudo apt update
sudo apt install python3 python3-venv python3-pip
```

**Fedora / RHEL**
```bash
sudo dnf install python3 python3-pip
```
</details>

## 二、下载代码

```bash
git clone https://cnb.cool/TJ-coding/gold-pet.git
cd gold-pet
```

没有 git 的话，在仓库页面点「下载源码」解压，再 `cd` 进目录。

---

## 三、创建虚拟环境并安装依赖

**强烈建议用虚拟环境** —— 否则会把 PySide6 装进系统 Python，可能影响其他程序。

```bash
python3 -m venv .venv
source .venv/bin/activate     # Windows 是 .venv\Scripts\activate
pip install -r requirements.txt
```

依赖只有 PySide6 与 Pillow，约 200MB，装一次即可。

> 如果 pip 很慢，可换国内镜像：
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

## 四、运行

```bash
python run.py
```

金娘会出现在**屏幕右下角**。

> **更省事的方式**：仓库根目录有一个 `run.sh`，会自动建虚拟环境、装依赖、启动，
> 首次运行一条命令搞定：
>
> ```bash
> chmod +x run.sh    # 首次需要赋可执行权限
> ./run.sh
> ```
>
> 它同样支持传参：`./run.sh --once`、`./run.sh --log-level DEBUG`。

### 首次运行可能遇到的问题

**1. macOS：提示「无法打开，因为它来自身份不明的开发者」**

这是因为源码运行不受 Gatekeeper 信任。用终端运行即可绕过（上面的 `python run.py` 就是终端运行）。

**2. Linux：报错 `qt.qpa.plugin: Could not load the Qt platform plugin "xcb"`**

缺系统库，按发行版装：

```bash
# Ubuntu / Debian
sudo apt install libxcb-cursor0 libxkbcommon-x11-0 libxcb-icccm4 \
  libxcb-image0 libxcb-keysyms1 libxcb-randr0 libxcb-render-util0 \
  libxcb-shape0 libgl1 libegl1 libfontconfig1 libdbus-1-3

# Fedora
sudo dnf install xcb-util-cursor libxkbcommon-x11 xcb-util-icccm \
  xcb-util-image xcb-util-keysyms libglvnd-egl fontconfig
```

**3. Linux：没有托盘图标**

部分桌面环境（如纯 GNOME、不带扩展）不支持系统托盘。此时关窗即退出程序，
菜单里也不会出现「隐藏到托盘」——这是正常的降级行为。

**4. macOS：菜单栏看不到图标**

macOS 的托盘叫「菜单栏」。图标应在右上角；若被「刘海」或其他图标挤掉，
可以试试收起其他菜单栏项。

## 五、怎么用

| 操作 | 效果 |
|---|---|
| 左键单击金娘 | 摸摸头 |
| 双击 | 立即刷新行情 |
| 按住拖动 | 换位置（会记住） |
| 长按 0.6 秒 | 撒娇 |
| **右键** | 打开菜单 |

右键菜单里有：立即刷新、切换单位、切换品种、走势图范围、**提醒历史**、**设置**、关于。

设置面板里可以配置：

- **提醒中心**：涨跌幅 / 到价 / 新高新低三类提醒，各自独立开关，还有冷却时间
- **勿扰模式**：设一段时间（支持跨零点，如 23:00–08:00），时段内**只静音系统通知**，
  金娘的气泡与台词照常，不会让你错过行情
- 不透明度、刷新间隔、开机自启、是否显示气泡 / 走势图

## 六、命令行参数（调试用）

```bash
python run.py --once                 # 只拉一次行情打印到终端，不启动界面
python run.py --metal silver --once  # 指定品种：gold / silver / platinum
python run.py --unit usd_oz          # 指定单位：cny_g（元/克） / usd_oz（美元/盎司）
python run.py --log-level DEBUG      # 详细日志
python run.py --version              # 看版本
```

`--once` 很适合排查「拉不到行情」的问题 —— 它会直接把错误打出来。

## 七、数据与配置文件在哪

| 内容 | 路径 |
|---|---|
| macOS | `~/.goldpet/` |
| Linux | `~/.goldpet/` |

里面有 `settings.json`（配置，可以直接手改后重启）、`history.json`（走势数据）、
`alert_history.json`（提醒历史）、`gold-pet.log`（日志）。

**桌宠跑到屏幕外了怎么办？** 删除 `settings.json` 里的 `pos` 字段后重启，
窗口会自动回到主屏右下角。

## 八、想自己打包

macOS 与 Linux 的打包**必须在对应系统上做**（苹果的 SDK 不允许跨平台构建）：

```bash
pip install -r requirements-dev.txt
pyinstaller --noconfirm --clean gold-pet.spec
```

- macOS 产物是 `dist/黄金桌宠.app`（注意：PyInstaller 在 macOS 上产出 `.app` 目录）
- Linux 产物是 `dist/黄金桌宠` 单文件可执行

未做代码签名的包，别人运行时会被系统警告，这是正常的。
